USER SIGNUP
==================================================

ENDPOINT
POST /users/signup

DESCRIPTION
Creates a new user. Supports storing user location and calendar preference.

HEADERS
Content-Type: application/json

REQUEST BODY (JSON)

{
"email": "test@test.com
",
"password": "test@123",
"name": "Test User",
"uid": null,
"auth_provider": "email",
"photoURL": null,
"location": "Gujarat",
"calendar_preference": "gujarati"
}

FIELD DETAILS

email REQUIRED User email
password REQUIRED Plain password (hashed in backend)
name OPTIONAL User display name
uid OPTIONAL Firebase / OAuth UID
auth_provider OPTIONAL Default: email
photoURL OPTIONAL Profile image URL
location OPTIONAL State name (Gujarat, Rajasthan, etc.)
calendar_preference OPTIONAL hindi | gujarati | bengali | rajasthani | gregorian

SUCCESS RESPONSE (201)

{
"message": "User created successfully",
"user": {
"id": 3,
"email": "test@test.com
",
"name": "Test User",
"uid": null,
"auth_provider": "email",
"photoURL": null,
"location": "Gujarat",
"calendar_preference": "gujarati",
"created_at": "2025-12-17T21:32:08"
},
"status": "created"
}

ERROR RESPONSES

400 Email already registered
500 Internal server error

3. UPLOAD CALENDAR CSV

ENDPOINT
POST /api/calendar/upload-csv

HEADERS
Content-Type: multipart/form-data

BODY (form-data)

Key Type Required Description
file File YES Calendar CSV file

CSV MUST HAVE THESE EXACT COLUMNS

gregorian_date,day,Hindi_Date,Gujarati_Date,Bengali_Date,Rajasthani_Date

SUCCESS RESPONSE

{
"message": "Calendar CSV uploaded successfully",
"rows_processed": 365
}

ERROR RESPONSES

400 Only CSV files allowed
500 Internal server error

4. GET CALENDAR OF A MONTH (MANUAL)

ENDPOINT
GET /api/calendar/month

HEADERS
Authorization: Bearer <ACCESS_TOKEN>

QUERY PARAMETERS

year REQUIRED Gregorian year (e.g. 1980)
month REQUIRED Gregorian month (1–12)
calendar OPTIONAL gregorian | hindi | gujarati | bengali | rajasthani

EXAMPLE REQUEST

GET /api/calendar/month?year=1980&month=1&calendar=rajasthani

SUCCESS RESPONSE

{
"calendar": "rajasthani",
"year": 1980,
"month": 1,
"total_days": 29,
"dates": [
{
"gregorian_date": "1980-01-03",
"day": "Thursday",
"regional_date": "1 Magha 2036"
}
]
}

ERROR RESPONSES

400 Invalid calendar type
500 Internal server error
